# Saved copies of the tool's data (not code)

These live in the tool's data folder (`~/Library/Application Support/LocalVideoStudio/`) and are copied here so
they are not lost with a Mac. To restore on a new Mac, copy each file back to the same place in the data folder.

| File here | Goes to (data folder) | What it is |
|---|---|---|
| `fonts/Montserrat-ExtraBold.ttf` | `fonts/` | V2 caption and label font (SIL Open Font License, github.com/JulietaUla/Montserrat) |
| `editing_styles/v2.json` | `editing_styles/` | V2 (Forgotten Flavors) editing style |
| `data/channel_kits.json` | `channel_kits.json` | Channels made from example videos (e.g. C1 inside the Era) and any kit changes |
| `data/checker_memory.json` | `checker_memory.json` | Sources the AI checker or an editor marked wrong for a dish/brand |
| `data/motion_history.json` | `motion_history.json` | Which motion designs each channel used lately |

`settings.json` is never stored here: it holds API keys and this repository is public.
Saved on 2 Oct 2026.
